# Contributing to A Pisces Sees All

Thank you for your interest in contributing to A Pisces Sees All.

## How to Contribute

1. **Fork the repository** and create a new branch for your changes.
2. **Make your edits** following the existing document structure and tone.
3. **Submit a pull request** describing what you changed and why.
4. **Wait for review** by the trustees before merging.

## Guidelines

- Keep language clear, respectful, and inclusive.
- Do not include personal data, contact details, or sensitive information in documents.
- Follow the Code of Conduct in all interactions.
- Reference official sources (Charity Commission, ICO, GOV.UK) where relevant.
- One topic per pull request where possible.

## Document Standards

- Use Markdown formatting.
- Include a "Last updated" date where applicable.
- Keep policies aligned with current UK law (UK GDPR, Data Protection Act 2018, Charities Act 2011).

## Questions

Open an issue or contact the trustees via the repository.
